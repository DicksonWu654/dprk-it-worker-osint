# Primary documents

Primary documents are linked from the source records in `data/sources/`. No local copies are currently bundled here. The repository intentionally omits court filings and other primary documents until each copy has been reviewed and, where necessary, redacted for contact selectors, victim information, identity documents, account numbers, and other sensitive material.

The source records preserve the publisher URL, publication date, access date, and (where useful) the SHA-256 hash of the reviewed upstream copy. A hash records provenance; it does not grant redistribution rights and does not mean that a copy is included in this repository.

Public availability or public-record status is not, by itself, a clearance to redistribute a document. If a reviewed, redacted copy is added later, keep its `local_copy` path under this directory and add a matching checksum manifest.
