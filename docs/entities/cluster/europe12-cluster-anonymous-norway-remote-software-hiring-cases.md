## Caveats

- Accent, language ability, claimed nationality, claimed geography, camera behavior, remote-work status, VPN/proxy use, VoIP use, payment routing, and unusual hours each require corroboration before supporting an identity, nationality, sanctions, or wrongdoing finding.
- PST's report stays at aggregate case context: 'several cases'; affected-company names, worker names, aliases, addresses, accounts, and raw technical selectors require separate evidence, and the dataset keeps them out of inference and collection.
- Retain as an aggregate Norway incident and defensive-control source. Preserve PST's 'probably' wording, the several-case aggregate, and non-adjudicative posture.
- Satisfactory work product addresses delivery quality; identity-continuity, access, sanctions, and revenue-diversion risk require separate review.
- This is an anonymous cluster and sector-level assessment; the record type covers assessment context rather than person, employer, recruiter, account, prosecution, judgment, or sanctions record.
- Use only corroborated, lawful, proportionate review with trained human assessment, documented reasons, bounded retention, accommodations, and a meaningful correction or appeal path.

## Source-backed context

- During the preceding year, PST learned of several cases in which unnamed Norwegian organizations were deceived into hiring probable North Korean IT workers for remote roles.
- The aggregate cases involved remote software-development work and false identity material linked both to fictitious personas and to real people whose identities had been stolen.
- PST states that there was no common affected sector and names no organization, worker, recruiter, account, or exact case count.
