- Keep employment fraud, insider-enabled access, logistical support, and external intrusion as separate evidence classes.
- Retain as an analytical boundary and defensive lesson. It distinguishes fraudulent employment from external cyber operations; this record is not a new malware or intrusion cluster.

## Source-backed context

- The advisory says DPRK IT workers normally perform IT work distinct from malicious cyber activity, while noting that some used contractor access to enable intrusions or provided logistical support such as virtual-infrastructure access, support for stolen-data sales, money laundering, virtual-currency transfers, or procurement. It explicitly says the workers themselves were unlikely to be involved in malicious cyber activity in some described support cases.
