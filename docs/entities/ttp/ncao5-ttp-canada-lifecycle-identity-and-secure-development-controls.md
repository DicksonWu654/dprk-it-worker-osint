## Source-backed context

- The advisory describes workers posing as freelancers based in other countries and offering mobile or web development, IT support, animation, database, online-platform, hardware and firmware work. It identifies VPNs, VPSs, VoIP, encrypted messaging, AI-enabled deepfakes and proxies lending personal information or employment-platform accounts as concealment methods. It recommends reviewing documents for inconsistencies, interviewing through multiple channels, using deepfake-detection strategies, and checking references and credentials.
