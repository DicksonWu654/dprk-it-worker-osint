## Source-backed context

- PSCORE interviewees described supervisors using screen-monitoring software, reprimanding workers who disabled it, and restricting both in-person and online communications. This adds a labor-governance dimension to monitoring already represented as a production-control TTP: the same controls can enforce isolation and constrain worker autonomy, not merely measure output.
