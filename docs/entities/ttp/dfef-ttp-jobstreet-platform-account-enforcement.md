## Source-backed context

- Jobstreet states that it monitors the DPRK fraudulent-employment campaign, detects and blocks suspicious candidate accounts, and proactively removes applications from actors it identifies as North Korean so those applications are no longer visible to hirers.
- Use stolen identities and deepfake assistance to create candidate accounts
- Use local facilitators to receive employer laptops and enable remote access
- Apply through employment platforms while concealing true location
- Platform-side detection and blocking of suspicious accounts
- Remove confirmed campaign applications from employer queues
- Use verified credentials, live practical tasks, and at least one higher-assurance interaction for high-risk roles
- Monitor overlapping or unusual login infrastructure without treating one IP or time-zone signal as proof
