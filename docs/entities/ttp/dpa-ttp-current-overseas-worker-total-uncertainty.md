## Caveats

- Historical figures, enforcement totals, vendor observations, incident counts, and application counts remain separate measures; a current workforce total requires a defined common denominator.
- Some deployments report student cover; this fact supplies context rather than a screening heuristic for students, remote workers, or nationals of any country.

## Source-backed context

- A/HRC/60/58 reports that overseas workers in information technology, construction and hospitality continued to be deployed after the Security Council repatriation deadline, reportedly under student cover in some cases.
- OHCHR expressly states that no credible current figure is available for the total number of DPRK overseas workers remaining abroad.
- Historical workforce estimates, incident counts and application volumes therefore must not be combined or relabeled as a current worldwide worker total.
