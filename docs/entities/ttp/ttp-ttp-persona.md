## Caveats

- Nationality, accent, appearance, contractor status and remote work are context signals; attribution requires corroboration.
- This is an official Japanese framing of already documented identity-fraud and laptop-farm methods; it supplies methods context rather than a new named network.

## Source-backed context

- PSIA gives the fraudulent-employment model a standalone hidden-threat treatment. It describes workers falsifying nationality, names and employment histories or impersonating real people to obtain freelance remote development work. It also describes U.S.-based helpers procuring false identity materials, operating laptop farms, receiving payroll and forwarding funds, while warning that contractors as well as employees can create sanctions and insider-access risk.
