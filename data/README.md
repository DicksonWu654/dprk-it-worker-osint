# data/

The source of truth. Everything else in the repository is generated from these files.

```
data/
  entities/<type>/<id>.json   one file per entity; <type> is one of
                              worker · persona · facilitator · front_company · organization ·
                              cluster · infrastructure · ttp · lead
  sources/<id>.json           one file per cited public document
```

Schemas: [`schema/entity.schema.json`](../schema/entity.schema.json), [`schema/source.schema.json`](../schema/source.schema.json). Field-by-field explanation: [`DATA-MODEL.md`](../DATA-MODEL.md).

Rules that `make validate` enforces:

- file name equals `id`; an entity lives in the folder for its `type`;
- every `source_id` anywhere in an entity exists in `data/sources/`;
- every source is cited by at least one entity;
- files are formatted by `tools/format.py` (two-space indent, UTF-8, trailing newline);
- no phone numbers, street addresses or card-number patterns; identity-document images are link-only.

Never edit `build/` or `docs/`; they are regenerated by `make build`.
